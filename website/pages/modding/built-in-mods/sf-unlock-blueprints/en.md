# SF Unlock Blueprints

> Historical reference mod. This package is not one of the two currently bundled mods. Source links point to the verified repository revision before its removal.

Changes recipe unlock requirements to the first Flame Altar hint.

## Package details

- Mod ID: `sf-unlock-blueprints`
- Target processes: client and Dedicated Server
- Runtime capability: no
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/81f9c5fe2d70ea4ba10896fb22a75b2d082800a6/reference-mods-0.9/sf-unlock-blueprints/src/mod.lua) for implementation details.
