    <div class="page-intro"><div class="eyebrow">SHROUDFORGE · THE PLATFORM</div><h1>What is a mod,<br>and what is ShroudForge?</h1><p class="lead">A mod is an add-on made by a player. ShroudForge is the program that finds mod packages, checks what they need, and connects supported features to Enshrouded.</p></div>
    <section class="process-map" aria-label="Difference between a mod and ShroudForge"><div class="map-heading"><span>ONE GAME, TWO DIFFERENT THINGS</span><h2>The mod is the add-on. ShroudForge is the loader.</h2><p>They work together, but they are not the same program.</p></div><div class="map-row"><article class="map-card"><b>THE MOD</b><strong>What a creator builds</strong><small>A folder of files with a name, instructions, and sometimes settings or game assets. It describes one feature, such as a new tool or a world editor.</small></article><span class="map-arrow">+</span><article class="map-card"><b>SHROUDFORGE</b><strong>What manages the mod</strong><small>It finds packages, checks their information and access requests, starts their supported parts at the right time, and reports results.</small></article><span class="map-arrow">→</span><article class="map-card"><b>ENSHROUDED</b><strong>Where the feature runs</strong><small>The game remains the game. ShroudForge connects the mod to the client or dedicated server installation.</small></article></div><div class="map-result"><b>IN SHORT</b><span>A mod adds a feature</span><span>ShroudForge loads and manages it</span><span>Enshrouded is the game it works with</span></div></section>
    <section class="system-map" aria-label="What ShroudForge does when the game starts"><div class="map-heading"><span>WHAT HAPPENS AT STARTUP</span><h2>From installed files to a clear result</h2><p>ShroudForge checks each package before it starts the parts that are supported.</p></div><div class="map-row"><article class="map-card"><b>1 · FIND</b><strong>Look in the mods folder</strong><small>Each mod has its own folder. ShroudForge reads its <code>mod.json</code> information card.</small></article><span class="map-arrow">→</span><article class="map-card"><b>2 · CHECK</b><strong>Check needs and compatibility</strong><small>It checks package details, declared capabilities, dependencies, target, and available game support.</small></article><span class="map-arrow">→</span><article class="map-card"><b>3 · RUN AT THE RIGHT TIME</b><strong>Prepare or start features</strong><small>Some changes are prepared before the game starts. Lua runtime features start while the game is running.</small></article></div><div class="map-branches"><article><span class="branch-tag">BEFORE THE GAME</span><h3>Prepare game files</h3><p>A mod that changes supported game assets needs the game closed. Start through ShroudForge so it can prepare and check the changes first.</p></article><article><span class="branch-tag live">WHILE THE GAME RUNS</span><h3>Run a Lua mod</h3><p>ShroudForge starts <code>src/mod.lua</code> in a separate Lua environment and gives it the declared ShroudForge or EML functions.</p></article></div><div class="map-result"><b>4 · SHOW THE RESULT</b><span><kbd>F9</kbd> manages mods and settings</span><span><kbd>F10</kbd> shows recorded messages</span></div></section>
    <section class="concept-grid"><article><span>THE GAME MOD LOADER</span><h2>ShroudForge is more than a list of mods</h2><p>Its parts include the Modloader window, the Debug Console, package checks, the updater, compatibility checks, the Lua API, and the native runtime used by some supported game features.</p></article><article><span>EML SUPPORT</span><h2>Older mods may still work</h2><p>ShroudForge can load many packages made for EML. It keeps the EML functions available, but a readable package is not a promise that the mod supports every game build or server.</p></article><article><span>PLAYER CONTROL</span><h2>Permissions say what a mod needs</h2><p>The mod lists requested capabilities in <code>mod.json</code>. ShroudForge checks these requests and shows whether a package is ready, blocked, or has a problem.</p></article><article><span>WHERE TO GO NEXT</span><h2>Learn the part you need</h2><p>Start with a small mod, learn its information files, or see how live Lua code and the native KFC runtime fit together.</p><button class="text-link" data-view="first">Build your first mod →</button><button class="text-link" data-view="runtime">Understand the runtime →</button></article></section>
    <div class="callout info"><b>For players</b><span>You usually install ShroudForge once beside the Enshrouded executable, then install a mod by following its creator’s instructions. The mod is separate from ShroudForge and can have its own compatibility requirements.</span></div>
