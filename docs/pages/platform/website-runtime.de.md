    <div class="page-intro"><div class="eyebrow">SHROUDFORGE · RUNTIME</div><h1>Lua Runtime und<br>KFC Native Runtime.</h1><p class="lead">„Runtime“ bedeutet, dass Code oder eine unterstützte Aktion läuft, während Enshrouded geöffnet ist. ShroudForge hat eine Lua-Umgebung für Mod-Code und eine eingebaute native Komponente namens KFC Runtime. Beide haben verschiedene Aufgaben.</p></div>
    <div class="callout info"><b>Der einfache Unterschied</b><span><code>src/mod.lua</code> enthält die Lua-Anweisungen des Mods. Die Lua Runtime ist der Ort, an dem ShroudForge diese ausführt. <code>kfc-runtime.dll</code> ist eine native ShroudForge-Komponente für einige freigegebene Aktionen im Spiel. Sie gehört zu ShroudForge und ist kein weiterer Mod zum Herunterladen.</span></div>
    <section class="process-map" aria-label="Wie Lua-Mods mit der nativen Runtime zusammenarbeiten"><div class="map-heading"><span>SO FUNKTIONIERT EIN LIVE-MOD</span><h2>Der Lua-Mod fragt an, ShroudForge leitet die Arbeit weiter</h2><p>Ein Mod nutzt dokumentierte Funktionen. Er muss die native DLL nicht direkt aufrufen.</p></div><div class="map-row"><article class="map-card"><b>1 · MOD-CODE</b><strong><code>src/mod.lua</code></strong><small>Der Ersteller schreibt Rückrufe und Aktionen in Lua. Jeder Mod läuft in einer eigenen Lua-Umgebung.</small></article><span class="map-arrow">→</span><article class="map-card"><b>2 · LUA RUNTIME</b><strong>ShroudForge führt den Mod aus</strong><small>Der Loader startet die Lebenszyklus-Funktionen und stellt erlaubte Funktionen bereit, zum Beispiel Einstellungen, Meldungen, UI-Aktionen oder unterstützte Spielfunktionen.</small></article><span class="map-arrow">→</span><article class="map-card"><b>3 · NATIVER DIENST BEI BEDARF</b><strong>KFC Runtime</strong><small>Für unterstützte tiefe Spieleingriffe ruft der Loader die eingebaute native Komponente auf und prüft das Ergebnis.</small></article></div><div class="map-result"><b>IM SPIEL</b><span>Der Mod erhält nur Funktionen, die der Loader bereitstellt</span><span>Nicht unterstützte native Aktionen bleiben gesperrt</span></div></section>
    <section class="system-map" aria-label="Was die KFC Runtime prüft"><div class="map-heading"><span>WARUM ES KFC RUNTIME GIBT</span><h2>Spielinternes kann sich mit Updates ändern</h2><p>Native Aktionen brauchen mehr als einen Lua-Funktionsnamen. Sie benötigen geprüfte Angaben für den richtigen Enshrouded-Build und das richtige Ziel.</p></div><div class="map-row"><article class="map-card"><b>1 · ERKENNEN</b><strong>Spielversion feststellen</strong><small>ShroudForge erkennt den Client oder Dedicated Server und den installierten Spiel-Build.</small></article><span class="map-arrow">→</span><article class="map-card"><b>2 · UNTERSTÜTZUNG PRÜFEN</b><strong>Geprüftes Profil verwenden</strong><small>Ein Profil beschreibt unterstützte Spielstrukturen und Aktionen für einen bestimmten Build und ein Ziel.</small></article><span class="map-arrow">→</span><article class="map-card"><b>3 · FREIGEBEN ODER STOPPEN</b><strong>Nur unterstützte Aktionen ausführen</strong><small>Die native Komponente prüft ihre Schnittstelle und das Profil. Fehlt die nötige Unterstützung, wird die Aktion nicht bereitgestellt.</small></article></div><div class="map-branches"><article><span class="branch-tag live">IN SHROUDFORGE ENTHALTEN</span><h3>Kein eigener KFC-Download</h3><p>Die Veröffentlichung enthält <code>shroudforge/kfc-runtime.dll</code>. Die Windows-Brücke lädt sie und prüft, ob ihre Schnittstelle zum Loader passt.</p></article><article><span class="branch-tag">NICHT JEDER MOD BRAUCHT ES</span><h3>Manche Live-Funktionen nutzen andere Dienste</h3><p>Ein Mod kann Einstellungen, Meldungen, UI- oder Netzwerkfunktionen nutzen, ohne dass jede Aktion ein nativer Spieleingriff ist. KFC kommt nur zum Einsatz, wenn eine Funktion nativen Zugriff braucht.</p></article></div></section>
    <section class="concept-grid"><article><span>VOR DEM START</span><h2>Spieldaten vorbereiten ist eine eigene Phase</h2><p>Ein Mod mit der Berechtigung <code>patch</code> kann unterstützte Spieldaten vorbereiten, bevor Enshrouded startet. Schließe das Spiel und starte es über ShroudForge.</p></article><article><span>WÄHREND DES SPIELS</span><h2>Die Berechtigung <code>runtime</code></h2><p>Ein Mod, der Live-Funktionen von ShroudForge nutzt, führt <code>runtime</code> in <code>mod.json</code> auf. Der Loader startet seine Lua-Rückrufe, während Client oder Server laufen.</p></article><article><span>EML-DLL-REGISTRIERUNG</span><h2><code>runtime-register-dll</code> ist etwas anderes</h2><p>Diese Berechtigung gilt für ein EML-Paket, das eine DLL aus seinem eigenen Mod-Ordner registriert. Diese mod-eigene DLL ist nicht ShroudForges eingebaute <code>kfc-runtime.dll</code>.</p></article><article><span>GRENZEN DER UNTERSTÜTZUNG</span><h2>Spielupdates können die Unterstützung ändern</h2><p>Native Aktionen hängen vom ausgewählten Client- oder Server-Profil ab. Dass ein Mod angezeigt wird oder sein Lua-Code startet, heißt nicht, dass jede native Aktion mit jedem Spiel-Build verfügbar ist.</p></article></section>
