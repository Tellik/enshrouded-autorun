    <div class="page-intro"><div class="eyebrow">SHROUDFORGE · RUNTIME</div><h1>Lua runtime and<br>KFC native runtime.</h1><p class="lead">“Runtime” means that code or a supported operation runs while Enshrouded is open. ShroudForge has a Lua environment for mod code and a built-in native component called KFC Runtime. They have different jobs.</p></div>
    <div class="callout info"><b>The simple difference</b><span><code>src/mod.lua</code> is the mod’s Lua instruction. The Lua runtime is where ShroudForge runs it. <code>kfc-runtime.dll</code> is a native ShroudForge component that provides some approved operations inside the game. It is included with ShroudForge and is not another mod to download.</span></div>
    <section class="process-map" aria-label="How Lua mods connect to the native runtime"><div class="map-heading"><span>HOW A LIVE MOD WORKS</span><h2>The Lua mod asks, ShroudForge routes the work</h2><p>A mod uses documented functions. It does not need to call the native DLL directly.</p></div><div class="map-row"><article class="map-card"><b>1 · MOD CODE</b><strong><code>src/mod.lua</code></strong><small>The creator writes callbacks and actions in Lua. Each mod runs in its own Lua environment.</small></article><span class="map-arrow">→</span><article class="map-card"><b>2 · LUA RUNTIME</b><strong>ShroudForge hosts the mod</strong><small>The loader starts lifecycle callbacks and exposes the functions allowed for that mod, such as settings, logs, UI actions, or supported game operations.</small></article><span class="map-arrow">→</span><article class="map-card"><b>3 · NATIVE PROVIDER WHEN NEEDED</b><strong>KFC Runtime</strong><small>For supported low-level game operations, the loader calls the built-in native provider and checks its result.</small></article></div><div class="map-result"><b>THE GAME</b><span>The mod only gets the functions the loader exposes</span><span>Unsupported native work stays unavailable</span></div></section>
    <section class="system-map" aria-label="What KFC Runtime checks"><div class="map-heading"><span>WHY KFC RUNTIME EXISTS</span><h2>Game internals can change between updates</h2><p>Native game operations need more than a Lua function name. They need reviewed information for the correct Enshrouded build and target.</p></div><div class="map-row"><article class="map-card"><b>1 · IDENTIFY</b><strong>Check the game build</strong><small>ShroudForge detects the client or dedicated server and the installed game build.</small></article><span class="map-arrow">→</span><article class="map-card"><b>2 · CHECK SUPPORT</b><strong>Use a reviewed profile</strong><small>A profile records supported game structures and operations for a particular build and target.</small></article><span class="map-arrow">→</span><article class="map-card"><b>3 · ALLOW OR STOP</b><strong>Use only supported operations</strong><small>The native provider checks its interface and profile. If required support is missing, that operation is not made available.</small></article></div><div class="map-branches"><article><span class="branch-tag live">INCLUDED WITH SHROUDFORGE</span><h3>No separate KFC download</h3><p>The release contains <code>shroudforge/kfc-runtime.dll</code>. The Windows bridge loads it and checks that its interface matches the loader.</p></article><article><span class="branch-tag">NOT EVERY MOD NEEDS IT</span><h3>Some live features use other services</h3><p>A mod can use settings, logging, UI, or network functions without making every action a native game operation. KFC is used only where the feature needs supported native access.</p></article></div></section>
    <section class="concept-grid"><article><span>BEFORE STARTUP</span><h2>Asset preparation is a separate phase</h2><p>A mod with the <code>patch</code> capability can prepare supported game assets before Enshrouded starts. Close the game and launch it through ShroudForge for this work.</p></article><article><span>WHILE PLAYING</span><h2>The <code>runtime</code> capability</h2><p>A mod that uses ShroudForge live-game functions declares <code>runtime</code> in <code>mod.json</code>. The loader starts its Lua callbacks while the client or server is running.</p></article><article><span>EML DLL REGISTRATION</span><h2><code>runtime-register-dll</code> is different</h2><p>This capability is for an EML package that registers a DLL from its own mod folder. That package-local DLL is not ShroudForge’s built-in <code>kfc-runtime.dll</code>.</p></article><article><span>SUPPORT BOUNDARIES</span><h2>Game updates can affect support</h2><p>Native operations depend on the selected client or server profile. A mod being listed or its Lua code starting does not mean every native operation is available on every game build.</p></article></section>
