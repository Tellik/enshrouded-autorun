# Mods currently included

The [mods/](https://github.com/bonsaibauer/shroudforge/tree/HEAD/mods) folder currently contains two mod packages shipped with ShroudForge. Their package files are the source for names, targets, and settings. Mod settings are stored in each package's `extended.mod.json`. They are separate from general Modloader preferences.

| Mod | ID | Target processes | Settings |
| --- | --- | --- | --- |
| [SF Survival](#doc-builtin-mod-sf-survival) | `sf-survival` | client and Dedicated Server | 8 |
| [SF Unlimited Flight](#doc-builtin-mod-sf-unlimited-flight) | `sf-unlimited-flight` | client and Dedicated Server | 5 |
