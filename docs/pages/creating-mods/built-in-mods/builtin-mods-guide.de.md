# Aktuell enthaltene Mods

Unter [mods/](https://github.com/bonsaibauer/shroudforge/tree/HEAD/mods) liegen derzeit zwei ausgelieferte Modpakete. Die Paketdateien sind die Quelle für Namen, Ziele und Einstellungen. Mod-Einstellungen stehen in der jeweiligen `extended.mod.json`. Sie sind getrennt von den allgemeinen Modloader-Einstellungen.

| Mod | ID | Zielprozesse | Einstellungen |
| --- | --- | --- | --- |
| [SF Survival](#doc-builtin-mod-sf-survival) | `sf-survival` | Client und Dedicated Server | 8 |
| [SF Unlimited Flight](#doc-builtin-mod-sf-unlimited-flight) | `sf-unlimited-flight` | Client und Dedicated Server | 5 |

## Frühere Referenzpakete

Die folgenden Seiten dokumentieren Modpakete, die nicht im aktuellen Ordner `mods/` liegen. Ihre Kennungen bleiben erreichbar, damit bestehende Links und die historischen Beschreibungen erhalten bleiben. Die World-Editor-Seiten gehören zu einem früheren Referenzpaket und beschreiben nicht die heutigen Modloader-Einstellungen.

| Frühere Seite | Thema |
| --- | --- |
| [SF Auto Stamina Refill](#doc-builtin-mod-sf-auto-stamina-refill) | Ausdauer automatisch auffüllen, mit der früheren Einstellung `autoRefill`. |
| [SF Infinite Item Split](#doc-builtin-mod-sf-infinite-item-split) | Verhalten beim Teilen von Gegenständen. |
| [SF Infinite Item Use](#doc-builtin-mod-sf-infinite-item-use) | Verbrauch von Gegenständen bei Benutzung. |
| [SF No Fall Damage](#doc-builtin-mod-sf-no-fall-damage) | Fallschaden. |
| [SF No Resource Cost](#doc-builtin-mod-sf-no-resource-cost) | Ressourcenverbrauch in unterstützten Aktionen. |
| [SF Production Time](#doc-builtin-mod-sf-production-time) | Produktionsdauer und die frühere Einstellung `seconds`. |
| [SF Unlock Blueprints](#doc-builtin-mod-sf-unlock-blueprints) | Frühere Freischaltbedingungen. |
| [World Editor](#doc-builtin-mod-world-editor) | Historische World-Editor-Optionen mit einzelnen Feldseiten. |
