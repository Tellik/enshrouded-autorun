# Steuerelement `text`

Für kurze Texte und Namen. Lege es bei einer Einstellung als `control` fest.

```json
{
  "settings": {
    "example": {"value": "text", "label": "Einzeiliges Textfeld", "control": "text"}
  }
}
```

Der Wert in `value` sollte zum Steuerelement passen. Weitere Regeln stehen unter [settings.<key>.control](#doc-field-settings-key-control).
