# Setting `general.compactMode`

Uses a denser Modloader layout.

## What it changes

Uses a denser Modloader layout.

## Default

`"nicht festgelegt"`





## Type and allowed values

Type: `boolean`.

No additional values or limits are declared by the schema.

## Example

This is a partial config snippet. Keep the other entries in your file.

```json
{
  "general": {}
}
```

## Configuration location

`shroudforge/config/modloader-config.json`, JSON path `/general/compactMode`. This configures the loader and is not copied into a mod package.

Source: `modules/loader-config/loader.schema.json` and `loader.default.json`.
