# Einstellung `general.reducedMotion`

Reduziert Bewegungs- und Übergangseffekte.

## Wirkung

Reduziert Bewegungs- und Übergangseffekte.

## Standardwert

`"nicht festgelegt"`





## Datentyp und zulässige Werte

Typ: `boolean`.

Keine zusätzlichen Werte oder Grenzen im Schema angegeben.

## Beispiel

Dies ist ein Teilausschnitt der Konfiguration. Andere Einträge bleiben bestehen.

```json
{
  "general": {}
}
```

## Ort in der Konfiguration

`shroudforge/config/modloader-config.json`, JSON-Pfad `/general/reducedMotion`. Diese Einstellung konfiguriert den Loader und wird nicht in das Mod-Paket kopiert.

Quelle: `modules/loader-config/loader.schema.json` und `loader.default.json`.
