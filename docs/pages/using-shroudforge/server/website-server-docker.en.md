    <div class="page-intro"><div class="eyebrow">QUICKSTART · MULTIPLAYER · PROTON DOCKER</div><h1>Set up the<br>Docker container.</h1><p class="lead">This guide is for <code>mornedhels/enshrouded-server</code> running with Proton. Add one environment setting so Proton loads the local ShroudForge DLL files.</p></div>
    <div class="callout info"><b>Required environment setting</b><span><code>WINEDLLOVERRIDES=dbghelp=native,builtin;winmm=native,builtin</code></span></div>
    <section class="server-docker-guide"><article><h3>Find your existing container</h3><p>On the Linux host, list containers and find the Enshrouded container in the <code>NAMES</code> column. The name is the Docker container label.</p><code class="command">docker ps -a</code></article><article><h3>Inspect its settings and game files</h3><p>Replace the example name with the one from the list. Save the image, port mapping, mount, environment values, and restart policy so you can recreate the same server. Environment values can contain private information. Do not share the full output publicly.</p><code class="command">NAME=YOUR_CONTAINER_NAME<br>docker inspect "$NAME" --format 'Image={{.Config.Image}} Ports={{json .HostConfig.PortBindings}} Mounts={{json .Mounts}} Environment={{json .Config.Env}} Restart={{.HostConfig.RestartPolicy.Name}}'</code><p>Find the mount whose destination is <code>/opt/enshrouded</code>. Its <code>Source</code> is the game folder on the Linux host. Confirm where the server executable is:</p><code class="command">docker exec "$NAME" find /opt/enshrouded -name enshrouded_server.exe -print</code><p>Back up the mounted host folder. Follow <a href="#server-files" data-view="server-files">Install ShroudForge server files</a> to copy the complete release and mod folder beside the executable.</p></article><article><h3>Recreate a container started with docker run</h3><p>Docker cannot change a container's environment after creation. Stop and remove the old container, then recreate it with the same image, port, mount, restart policy, and all existing environment values. This example uses UDP port <code>15637</code>. Replace the host path and image with your inspected values.</p><code class="command">NAME=YOUR_CONTAINER_NAME<br>docker stop "$NAME"<br>docker rm "$NAME"<br>docker run -d --name "$NAME" --restart unless-stopped -p 15637:15637/udp -v /YOUR/HOST/GAMEFILES:/opt/enshrouded -e 'WINEDLLOVERRIDES=dbghelp=native,builtin;winmm=native,builtin' -e 'SERVER_QUERYPORT=15637' YOUR_IMAGE</code><p>Include every environment option from the old container. The game files stay in the mounted host folder when you remove and recreate the container. In the port mapping, the number before the colon is the host port and the number after it is the container port. Keep your existing mapping if it differs.</p></article><article><h3>Update a Docker Compose service</h3><p>Add the variable under <code>environment</code> in the existing service. Keep its current image, ports, volumes, and other settings. This example shows the correct Compose format:</p><code class="command">services:<br>  enshrouded:<br>    image: mornedhels/enshrouded-server:dev-proton<br>    container_name: enshrouded<br>    restart: unless-stopped<br>    ports:<br>      - "15637:15637/udp"<br>    volumes:<br>      - /YOUR/HOST/GAMEFILES:/opt/enshrouded<br>    environment:<br>      WINEDLLOVERRIDES: "dbghelp=native,builtin;winmm=native,builtin"<br>      SERVER_QUERYPORT: "15637"</code><p>Save the file, then recreate the service using its Compose service name:</p><code class="command">docker compose up -d --force-recreate enshrouded</code></article><article><h3>Check the result</h3><p>After startup, check <code>shroudforge/logs/shroudforge-server.log</code> in the mounted host folder. The ShroudForge release includes <code>dbghelp.dll</code>, <code>winmm.dll</code>, and other required files. Copy the complete release ZIP contents.</p></article></section>
