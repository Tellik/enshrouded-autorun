    <div class="page-intro"><div class="eyebrow">QUICKSTART · MULTIPLAYER · PROTON-DOCKER</div><h1>Docker-Container<br>einrichten.</h1><p class="lead">Diese Anleitung gilt für <code>mornedhels/enshrouded-server</code> mit Proton. Ergänze eine Umgebungsvariable, damit Proton die lokalen ShroudForge-DLLs lädt.</p></div>
    <div class="callout info"><b>Erforderliche Umgebungsvariable</b><span><code>WINEDLLOVERRIDES=dbghelp=native,builtin;winmm=native,builtin</code></span></div>
    <section class="server-docker-guide"><article><h3>Vorhandenen Container finden</h3><p>Liste auf dem Linux-Host die Container auf und suche den Enshrouded-Container in der Spalte <code>NAMES</code>. Der Name ist die Bezeichnung des Docker-Containers.</p><code class="command">docker ps -a</code></article><article><h3>Einstellungen und Spieldateien prüfen</h3><p>Ersetze den Beispielnamen durch den Namen aus der Liste. Notiere Image, Portzuordnung, Einbindung, Umgebungsvariablen und Neustartregel, damit du den gleichen Server neu erstellen kannst. Umgebungsvariablen können private Werte enthalten. Teile die vollständige Ausgabe nicht öffentlich.</p><code class="command">NAME=YOUR_CONTAINER_NAME<br>docker inspect "$NAME" --format 'Image={{.Config.Image}} Ports={{json .HostConfig.PortBindings}} Mounts={{json .Mounts}} Environment={{json .Config.Env}} Restart={{.HostConfig.RestartPolicy.Name}}'</code><p>Suche die Einbindung mit dem Ziel <code>/opt/enshrouded</code>. Der zugehörige <code>Source</code>-Pfad ist der Spieleordner auf dem Linux-Host. Prüfe den Ort der Serverdatei:</p><code class="command">docker exec "$NAME" find /opt/enshrouded -name enshrouded_server.exe -print</code><p>Sichere den eingebundenen Hostordner. Folge der Anleitung <a href="#server-files" data-view="server-files">ShroudForge-Dateien auf dem Server installieren</a>, um den vollständigen Release und den Mod-Ordner neben die Serverdatei zu kopieren.</p></article><article><h3>Container aus docker run neu erstellen</h3><p>Die Umgebungsvariablen eines erstellten Containers lassen sich nicht ändern. Stoppe und entferne den alten Container und erstelle ihn mit demselben Image, Port, Volume, derselben Neustartregel und allen bisherigen Umgebungsvariablen neu. Das Beispiel verwendet UDP-Port <code>15637</code>. Ersetze Hostpfad und Image durch deine Werte.</p><code class="command">NAME=YOUR_CONTAINER_NAME<br>docker stop "$NAME"<br>docker rm "$NAME"<br>docker run -d --name "$NAME" --restart unless-stopped -p 15637:15637/udp -v /YOUR/HOST/GAMEFILES:/opt/enshrouded -e 'WINEDLLOVERRIDES=dbghelp=native,builtin;winmm=native,builtin' -e 'SERVER_QUERYPORT=15637' YOUR_IMAGE</code><p>Übernimm auch jede bisherige Umgebungsvariable. Die Spieldateien bleiben im eingebundenen Hostordner, wenn du den Container entfernst und neu erstellst. Bei der Portzuordnung steht links der Host-Port und rechts der Container-Port. Behalte deine bisherige Zuordnung bei, falls sie anders ist.</p></article><article><h3>Docker-Compose-Dienst anpassen</h3><p>Ergänze die Variable unter <code>environment</code> beim bestehenden Dienst. Behalte Image, Ports, Volumes und weitere Einstellungen bei. Das Beispiel zeigt die Compose-Schreibweise:</p><code class="command">services:<br>  enshrouded:<br>    image: mornedhels/enshrouded-server:dev-proton<br>    container_name: enshrouded<br>    restart: unless-stopped<br>    ports:<br>      - "15637:15637/udp"<br>    volumes:<br>      - /YOUR/HOST/GAMEFILES:/opt/enshrouded<br>    environment:<br>      WINEDLLOVERRIDES: "dbghelp=native,builtin;winmm=native,builtin"<br>      SERVER_QUERYPORT: "15637"</code><p>Speichere die Datei und erstelle den Dienst mit seinem Compose-Dienstnamen neu:</p><code class="command">docker compose up -d --force-recreate enshrouded</code></article><article><h3>Ergebnis prüfen</h3><p>Prüfe nach dem Start <code>shroudforge/logs/shroudforge-server.log</code> im eingebundenen Hostordner. Die ShroudForge-ZIP enthält <code>dbghelp.dll</code>, <code>winmm.dll</code> und weitere Dateien. Kopiere den vollständigen ZIP-Inhalt.</p></article></section>
