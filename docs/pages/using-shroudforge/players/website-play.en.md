    <div class="page-intro"><div class="eyebrow">FOR PLAYERS</div><h1>Set up ShroudForge<br>and add a mod.</h1><p class="lead">Follow these steps to put ShroudForge in your game folder, open the Mods window, and add a mod you have downloaded.</p></div>
    <div class="callout info"><b>Before you start</b><span>Close Enshrouded. A “mod” is an extra made by a player that changes or adds something in the game. ShroudForge has a window that shows your mods. Your game folder is the one containing <code>enshrouded.exe</code>.</span></div>
    <div class="step-list"><article><span class="step-num">01</span><div><h2>Download ShroudForge</h2><p>Open the latest release and save the Windows ZIP file. A ZIP is a packed folder. You need to unpack it before use.</p><a class="button small primary" href="https://github.com/bonsaibauer/shroudforge/releases/latest" target="_blank" rel="noreferrer">Download ShroudForge ↗</a></div></article><article><span class="step-num">02</span><div><h2>Copy the files into the game folder</h2><p>Right-click the ZIP file and choose “Extract All”. Open the unpacked folder and copy <b>all files and folders</b> from the ZIP beside <code>enshrouded.exe</code>.</p><div class="folder-tree"><span>Enshrouded/ <em>your game folder</em></span><span class="tree-child">├─ enshrouded.exe <em>the game</em></span><span class="tree-child">├─ dbghelp.dll <em>ShroudForge DLL</em></span><span class="tree-child">├─ dinput8.dll <em>ShroudForge DLL</em></span><span class="tree-child">├─ winmm.dll <em>ShroudForge game hook</em></span><span class="tree-child">├─ shroudforge/ <em>loader, libraries, and settings</em></span><span class="tree-grandchild">└─ shroudforge.exe</span><span class="tree-child">└─ mods/ <em>mod packages</em></span></div><p class="muted">A common Steam folder is:<br><code>C:Program Files (x86)SteamsteamappscommonEnshrouded</code></p></div></article><article><span class="step-num">03</span><div><h2>Start the game and open the Mods window</h2><p>Start Enshrouded. Press <kbd>F9</kbd> to open the ShroudForge window and see your mods. Press <kbd>F10</kbd> to read messages from ShroudForge if something is not working.</p><div class="key-row"><span><kbd>F9</kbd><small>See and switch on mods</small></span><span><kbd>F10</kbd><small>Read messages if there is a problem</small></span></div></div></article><article><span class="step-num">04</span><div><h2>Find and add a mod</h2><p>Look for Enshrouded mods on community sites. Read the creator instructions, then download and unpack the mod. Copy its folder into <code>Enshrouded/mods/</code>.</p><a class="text-link" href="https://www.nexusmods.com/enshrouded/mods/" target="_blank" rel="noreferrer">Browse Enshrouded mods on Nexus Mods ↗</a><div class="folder-tree"><span>mods/ <em>the folder for all mods</em></span><span class="tree-child">└─ my-mod/ <em>one mod</em></span><span class="tree-grandchild">├─ mod.json <em>information about the mod</em></span><span class="tree-grandchild">├─ extended.mod.json <em>extra settings, if included</em></span><span class="tree-grandchild">└─ src/mod.lua <em>the mod instructions</em></span></div><p>Follow the mod creator’s installation instructions.</p></div></article><article><span class="step-num">05</span><div><h2>Check that the mod is ready</h2><p>Press <kbd>F9</kbd> and open Installed. If your mod is listed, you can switch it on. Some mods need you to restart the game.</p><div class="callout warning"><b>Mods that change game files</b><span>These mods need to be prepared before the game starts. Close the game and start it with this file from the game folder:</span><code class="command">./shroudforge/shroudforge.exe launch "."</code></div></div></article></div>
