# Archived source captures

These text files preserve scripts from specific game-build investigations and local sessions. They are not imported by the project and are not available as current development actions.

Reusable profile-export and investigation actions live under `dev/profiles/`. Use those maintained actions for new work. Historical captures remain unchanged so their recorded paths and checksums continue to match `manifest.json`.

Original executable files and binary captures remain local under `dev/profiles/captures/`. They are not compiler outputs.
