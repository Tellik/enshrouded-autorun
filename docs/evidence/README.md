# Evidence and archive

This directory keeps dated investigations, source captures, and documents retained for historical reference. These records explain what was examined at a particular time. They are not instructions for the current workflow. Use the guides under `../development/`, `../modding/`, and `../runtime/` for current behavior.

- `runtime/` contains dated runtime and game-build investigations with their source captures.
- `game-builds/` contains focused investigations of specific game builds and loaded resources.
- `eml-archive/` preserves the imported EML reference material. It is not the current ShroudForge installation guide.
- `repository-history/` keeps completed repository audits and previous document snapshots as historical records.

Put a new user or developer guide in its current topic directory. Add a link to historical evidence only when it supports a specific claim.
